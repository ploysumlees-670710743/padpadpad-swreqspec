# คู่มือทดลอง Prototype: ลงคะแนนสถานที่ค่าย (UC-08)

คู่มือนี้ใช้สำหรับเปิดและทดลองหน้าต้นแบบตาม AC-VOT-01 ถึง AC-VOT-03 โดยข้อมูลสถานที่เป็นข้อมูลจำลองตาม Q-02

## 1. เตรียมเครื่อง

ติดตั้ง dependencies ที่โฟลเดอร์หลักของ repository:

```bash
pip install -r requirements.txt
npm --prefix frontend ci
```

## 2. เปิดระบบ

เปิด 2 terminals ที่โฟลเดอร์หลักของ repository

**Terminal 1 — Backend**

```bash
python -m uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2 — Frontend**

```bash
npm --prefix frontend run dev -- --host 0.0.0.0
```

เปิด URL ที่ Vite แสดงใน terminal หรือเปิด forwarded port ของ frontend ใน Codespaces

## 3. ทดลองหน้าเว็บ

1. หน้าแรกแสดงสถานที่จำลอง 3 แห่ง พร้อมภาพ สรุป และคะแนนเริ่มต้น
2. เลือกสถานที่หนึ่งแห่ง แล้วตรวจว่าปุ่มยืนยันเปิดใช้งาน
3. กดยืนยัน ตรวจว่าคะแนนของสถานที่นั้นเพิ่มขึ้น 1 และมีข้อความ “ท่านได้ใช้สิทธิ์ไปแล้ว”
4. ตรวจว่าปุ่มยืนยันและตัวเลือกถูกปิดหลังใช้สิทธิ์

การเลือกและยืนยันบนหน้าเว็บเป็นการจำลองในหน่วยความจำของ browser เท่านั้น การรีโหลดหน้าเว็บจะเริ่มสถานะจำลองใหม่ คะแนนและสิทธิ์จึงไม่ถูกเก็บถาวร

## 4. รัน automated tests

จากโฟลเดอร์หลักของ repository:

```bash
PYTHONPATH=. pytest -v backend/tests
npm --prefix frontend test
```

Backend tests ตรวจ API และการป้องกันการลงคะแนนซ้ำ ส่วน frontend tests ตรวจการแสดงรายการ การเลือก/ยืนยัน การใช้สิทธิ์ซ้ำ และกรณีคะแนนสูงสุดเสมอ

## ขอบเขตของ Prototype

- Role บนหน้าเว็บจำลองเป็น `lecturer`; ยังไม่ได้เชื่อมระบบยืนยันตัวตนกลางหรือ role จริง
- รายการสถานที่ที่แสดงเป็นข้อมูลจำลอง ไม่ได้อ่านจากแหล่งข้อมูลสถานที่จริง
- การยืนยันคะแนนจากหน้าเว็บยังไม่เรียก API สำหรับบันทึกคะแนน จึงไม่ใช่หลักฐานว่าคะแนนจะคงอยู่หลังปิดหรือรีโหลดหน้า
- ใช้การรัน automated tests เพื่อตรวจพฤติกรรม backend/API เพิ่มเติมตาม AC; การสาธิตหน้าเว็บเพียงอย่างเดียวไม่ยืนยันการทำงานจริงของระบบยืนยันตัวตนหรือการบันทึกคะแนนแบบถาวร
