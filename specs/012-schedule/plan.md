# แผนทางเทคนิค: UC-12 ดูกำหนดและกิจกรรม

## 1. สรุปแนวทาง

1. สร้างหน้าสำหรับคณะกรรมการเลือกและตรวจทานโครงการค่ายก่อนเผยแพร่ตาม FR-SCH-01 และ FR-SCH-02
2. ให้คณะกรรมการกด “เผยแพร่ประกาศ” ซึ่งเป็นการประกาศและเผยแพร่ในขั้นตอนเดียวตาม FR-SCH-03 และ ASM-SCH-04
3. ตรวจสอบซ้ำว่าข้อมูล 4 ส่วนครบถ้วนไม่มีฟิลด์ว่างและสถานะเป็น “อนุมัติแล้ว” ตาม FR-SCH-04 และ ASM-SCH-05
4. เปลี่ยนสถานะเป็น “เผยแพร่แล้ว” เมื่อผ่านเงื่อนไข และปฏิเสธพร้อม Pop-up เมื่อยัง “รออนุมัติ” ตาม FR-SCH-05, FR-SCH-07, AC-SCH-01 และ AC-SCH-02
5. แสดงรายละเอียดค่ายที่เผยแพร่แล้วให้นักศึกษาเข้าชมตาม FR-SCH-06, ASM-SCH-06 และ AC-SCH-03

## 3. โมเดลข้อมูล

| Entity | ฟิลด์หลัก | รองรับ |
| :--- | :--- | :--- |
| CampProject | project_id, camp_details, schedule, location, activities, status, approval_status | FR-SCH-01, FR-SCH-02, FR-SCH-04, FR-SCH-05, FR-SCH-07, ASM-SCH-02, ASM-SCH-03 |
| PublishedCampView | project_id, camp_details, schedule, location, activities | FR-SCH-06, AC-SCH-03, ASM-SCH-06 |

`CampProject.status` ต้องรองรับอย่างน้อย “รออนุมัติ” และ “เผยแพร่แล้ว” ส่วน `approval_status` ต้องรองรับ “อนุมัติแล้ว” จากอาจารย์ตาม FR-SCH-04, FR-SCH-05, FR-SCH-07 และ AC-SCH-02 ฟิลด์ทั้ง 4 ส่วนต้องตรวจว่าไม่ว่างก่อนเผยแพร่ตาม ASM-SCH-02; ฟิลด์อื่นนอกเหนือจาก spec ยังไม่กำหนดเพิ่มเติม

## 4. API / หน้าจอ

- `GET /committee/camp-projects`: แสดงรายการโครงการที่คณะกรรมการเลือกได้ตาม FR-SCH-01; input คือสิทธิ์คณะกรรมการ และ output คือรายการโครงการพร้อมสถานะ
- `GET /committee/camp-projects/{project_id}`: แสดงรายละเอียดค่าย 4 ส่วนให้คณะกรรมการตรวจทานตาม FR-SCH-02; output คือรายละเอียดค่าย กำหนดการ สถานที่ และกิจกรรม
- `POST /committee/camp-projects/{project_id}/publish`: รับคำขอเผยแพร่จากปุ่ม “เผยแพร่ประกาศ” ตาม FR-SCH-03; ตรวจข้อมูล 4 ส่วนและ `approval_status` ตาม FR-SCH-04; output คือสถานะ “เผยแพร่แล้ว” ตาม FR-SCH-05 หรือผลปฏิเสธพร้อมข้อความ Pop-up ตาม FR-SCH-07
- `GET /student/camp-projects`: แสดงเฉพาะโครงการที่มีสถานะ “เผยแพร่แล้ว” ตาม FR-SCH-06 และ ASM-SCH-06; output คือรายการค่ายที่นักศึกษาเข้าถึงได้
- `GET /student/camp-projects/{project_id}`: แสดงรายละเอียดค่าย กำหนดการ สถานที่ และกิจกรรมที่เผยแพร่แล้วตาม FR-SCH-06 และ AC-SCH-03
- `PublishErrorPopup`: แสดงข้อความ “ไม่สามารถเผยแพร่ได้ เนื่องจากโครงการยังไม่ได้รับการอนุมัติจากอาจารย์” และคงสถานะ “รออนุมัติ” ตาม FR-SCH-07 และ AC-SCH-02

## 7. ลำดับงาน

1. สร้างโมเดล CampProject และสถานะโครงการตาม FR-SCH-04, FR-SCH-05, FR-SCH-07 และ ASM-SCH-03
2. สร้างหน้ารายการและหน้ารายละเอียดสำหรับคณะกรรมการเลือกและตรวจทานโครงการตาม FR-SCH-01 และ FR-SCH-02
3. สร้างปุ่ม “เผยแพร่ประกาศ” และคำขอเผยแพร่ตาม FR-SCH-03 และ ASM-SCH-04
4. สร้างการตรวจสอบข้อมูล 4 ส่วนว่าไม่ว่างและตรวจ `approval_status` ซ้ำก่อนเผยแพร่ตาม FR-SCH-04 และ ASM-SCH-02
5. สร้างการเปลี่ยนสถานะเป็น “เผยแพร่แล้ว” เมื่อผ่านเงื่อนไขตาม FR-SCH-05 และ AC-SCH-01
6. สร้างการปฏิเสธการเผยแพร่ Pop-up และคงสถานะ “รออนุมัติ” ตาม FR-SCH-07 และ AC-SCH-02
7. สร้างหน้าค้นหาและหน้ารายละเอียดสำหรับนักศึกษา โดยกรองเฉพาะค่าย “เผยแพร่แล้ว” ตาม FR-SCH-06 และ AC-SCH-03
8. ทดสอบ AC-SCH-01, AC-SCH-02 และ AC-SCH-03 ตามตารางแผนทดสอบ
