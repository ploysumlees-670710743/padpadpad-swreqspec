# Prompt Log: UC-01 Clarify Phase

## Questions Asked by AI
1. **[Validation]** ระบบต้องมี Validation ตรวจสอบเบอร์โทรศัพท์ และป้องกันการตั้งชื่อชุมชนซ้ำกันในสถานที่เดียวกันหรือไม่?
2. **[Attachment]** ข้อปฏิบัติชุมชน (local rules) ต้องรองรับไฟล์แนบหรือไม่ หรือเป็นเพียง Text?
3. **[Access Control]** คณะกรรมการแก้ไขข้อมูลข้ามค่ายได้หรือไม่?

## User Answers & Decisions
1. **Validation:** ไม่รู้ ต้องถามอาจารย์/ผู้ใช้งานเพิ่มเติมเกี่ยวกับเงื่อนไขชื่อซ้ำและเบอร์โทร
2. **Attachment:** ไม่รู้ ต้องถามอาจารย์/ผู้ใช้งานเพิ่มเติมเกี่ยวกับขอบเขตการรองรับไฟล์แนบ
3. **Access Control:** ไม่สามารถทำข้ามค่ายได้ คณะกรรมการจัดการได้เฉพาะค่ายที่ตนเองรับผิดชอบเท่านั้น
