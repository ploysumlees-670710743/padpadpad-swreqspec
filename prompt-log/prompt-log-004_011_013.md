4. “กลุ่ม” และ “ฝ่าย” เป็นหน่วยจัดสังกัดชนิดเดียวกันหรือเป็นตัวเลือกที่แยกประเภทกัน?

2. หากยังไม่เริ่มงานไม่ต้องเก็บไว้ แต่ถ้าหากประกาศหรือเริ่มงานแล้วให้เก็บประวัติสังกัดเดิมไว้ เมื่อมีการย้าย
3. แจ้งเตือนผู้เข้าร่วมหลังย้ายสังกัดสำเร็จ
4. ผู้เข้าร่วมจะต้องอยู่ฝ่ายใดฝ่ายหนึ่งเท่านั้น ส่วนคณะกรรมการจะต้องอยู่ฝ่ายใดผ่านหนึ่งเท่านั้น จะไม่มีกรณีใดที่จะต้องอยู่ทั้งผ่านและกลุ่ม
5. หน้าต่างยืนยันต้องแสดง ผู้เข้าร่วม + สังกัดเดิม + สังกัดใหม่ + ปุ่มยืนยัน/ยกเลิก
6. รายชื่อผู้ผ่านการคัดเลือกเป็นชุดเดียวกัน แต่ระบบควรมีสถานะ “รอจัดกลุ่ม” / “จัดกลุ่มแล้ว”
